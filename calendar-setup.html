Connect your calendar

Tidy Tab Office · optional feature · about 10 minutes, once

EnglishTiếng Việt

Meetings is an optional feature, off by default. Everything else in Tidy Tab Office works without it. Turn it on only if you want the secretary in the Meeting room to show your next meetings, remind you 5 minutes before and give you a Join button. Pick one option:

  • Option A – Google Calendar with your own Google client (recommended, works with Google Workspace accounts).
  • Option B – Private iCal link (fastest, if your Google account allows it).

Why your own client? Your calendar goes straight from Google to your browser. Nobody else, including the developer, can see it, and you can revoke access any time.

Option A – Google Calendar

1. Open the setup in Tidy Tab Office

Open the office and click the secretary in the Meeting room → Set up calendar… (or Settings → Meetings → Set up calendar…). Tick I allow Tidy Tab Office to read my calendar and choose Google Calendar. You will see your Redirect URI, for example https://abcdefghijklmnop.chromiumapp.org/, with a Copy button. Keep this window open.

2. Create a Google Cloud project

  1. Go to console.cloud.google.com and sign in with the account whose calendar you want to see.
  2. Top bar → project picker → New project. Name it Tidy Tab Calendar → Create, then select it.

3. Turn on the Google Calendar API

  1. Menu → APIs & Services → Library.
  2. Search Google Calendar API → Enable.

4. Set up the consent screen

  1. Menu → Google Auth Platform (or OAuth consent screen) → Get started.
  2. App name: Tidy Tab Calendar. Support email: your email.
  3. Audience:
    • Internal if you use a company Google Workspace account and the option is available.
    • Otherwise External. Keep the publishing status at Testing and add your own email under Test users.
  4. Contact email → agree → Create.

5. Create the client

  1. Clients → Create client → Application type: Web application.
  2. Under Authorized redirect URIs (not JavaScript origins) → Add URI → paste the Redirect URI from step 1, including the final /.
  3. Create, then copy the Client ID (ends with .apps.googleusercontent.com). You do not need the client secret.

6. Connect

  1. Back in the Tidy Tab Office setup window, paste the Client ID → Connect.
  2. Choose your account. If Google says "Google hasn't verified this app", that is expected: it is your own app. Click Continue.
  3. Allow View events on all your calendars. The secretary now shows your next meetings.

Troubleshooting

  • redirect_uri_mismatch: the URI in Google Cloud does not exactly match the one in Settings. Copy it again, keep the trailing /, and put it under Authorized redirect URIs.
  • access_denied / not a test user: add your email under Audience → Test users.
  • Your organization blocks it: your Workspace admin may restrict third-party apps or Cloud projects. Use Option B or ask your admin.
  • "Needs to reconnect" every day: click Connect again. Google may ask you to sign in again from time to time.

Option B – Private iCal link

  1. Open Google Calendar → ⚙ Settings → your calendar → Integrate calendar.
  2. Copy Secret address in iCal format. If you don't see it, your admin has turned it off: use Option A.
  3. In Tidy Tab Office, open the setup (click the secretary → Set up calendar…), tick I allow…, choose Secret iCal link → paste → Chrome asks permission to access calendar.google.com → Allow.

Treat the secret link like a password. Do not use the public address unless your calendar is public.

Turn it off

Settings → Meetings → Turn off. To fully revoke, remove the app at myaccount.google.com/permissions, or delete the Cloud project. See also our privacy policy.

Kết nối lịch

Lịch họp là tính năng tuỳ chọn, mặc định tắt. Các tính năng khác vẫn chạy đầy đủ khi không có lịch. Chỉ bật khi bạn muốn thư ký ở Phòng họp hiện lịch họp sắp tới, nhắc trước 5 phút và có nút Vào họp. Chọn một cách:

  • Cách A – Google Calendar bằng OAuth client của chính bạn (khuyên dùng, chạy được với tài khoản công ty Google Workspace).
  • Cách B – Link iCal bí mật (nhanh nhất, nếu tài khoản cho phép).

Vì sao dùng client của chính bạn? Lịch đi thẳng từ Google về trình duyệt của bạn. Không ai khác, kể cả nhà phát triển, xem được. Bạn thu hồi quyền lúc nào cũng được.

Cách A – Google Calendar

  1. Mở trình thiết lập: mở văn phòng, bấm thư ký ở Phòng họp → Thiết lập lịch… (hoặc Cài đặt → Lịch họp → Thiết lập lịch…). Tick Tôi đồng ý… rồi chọn Google Calendar. Màn hình hiện Redirect URI, ví dụ https://abcdefghijklmnop.chromiumapp.org/, có nút Sao chép. Giữ cửa sổ này.
  2. Tạo project: vào console.cloud.google.com bằng tài khoản có lịch cần xem → chọn project → New project → đặt tên Tidy Tab Calendar → Create, rồi chọn project đó.
  3. Bật Google Calendar API: menu → APIs & Services → Library → tìm Google Calendar API → Enable.
  4. Màn hình đồng ý: menu → Google Auth Platform → Get started → tên app Tidy Tab Calendar, email hỗ trợ là email của bạn. Audience: chọn Internal nếu là tài khoản công ty và có lựa chọn này; nếu không thì External, để trạng thái Testing và thêm email của bạn vào Test users.
  5. Tạo client: Clients → Create client → loại Web application → mục Authorized redirect URIs (không phải JavaScript origins) → Add URI → dán Redirect URI ở bước 1, giữ dấu / cuối → Create → sao chép Client ID. Không cần client secret.
  6. Kết nối: quay lại cửa sổ thiết lập của Tidy Tab Office, dán Client ID → Kết nối → chọn tài khoản. Nếu Google báo "Google hasn't verified this app" là bình thường vì đây là app của chính bạn → Continue → cho phép xem sự kiện.

Lỗi thường gặp

  • redirect_uri_mismatch: URI trong Google Cloud không khớp hoàn toàn. Sao chép lại, giữ dấu / cuối, dán vào Authorized redirect URIs.
  • access_denied: chưa thêm email vào Test users.
  • Công ty chặn: admin Workspace có thể hạn chế app bên thứ ba. Dùng Cách B hoặc hỏi admin.

Cách B – Link iCal bí mật

  1. Google Calendar → ⚙ Cài đặt → chọn lịch → Tích hợp lịch.
  2. Sao chép Địa chỉ bí mật ở định dạng iCal. Không thấy mục này nghĩa là admin đã tắt: dùng Cách A.
  3. Mở trình thiết lập (bấm thư ký → Thiết lập lịch…), tick Tôi đồng ý…, chọn Link iCal bí mật → dán → Chrome hỏi quyền truy cập calendar.google.com → Cho phép.

Tắt lịch

Cài đặt → Lịch họp → Tắt lịch. Muốn thu hồi hẳn: gỡ app tại myaccount.google.com/permissions hoặc xoá project Cloud. Xem thêm chính sách riêng tư.
